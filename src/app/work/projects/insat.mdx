## Overview

inSAT is a multi-tenant digital SAT practice platform. Each academy gets its own admins, students, and results, fully isolated from every other academy. Students can drive their own practice, or an academy can assign tests and follow each student's progress.

## Technical Highlights

- **Adaptive tests**: each form is assembled fresh for the student, so no question is served twice.
- **Server-side scoring**: results, skill analysis, and the next practice set come from the API.
- **Two institution modes**: self-guided practice or academy-managed groups and assignments.
- **Custom tests**: managed academies can upload their own questions or write them with AI.
- **Tenant isolation**: the browser never reads the database directly, and the API scopes every query to one institution.

## Technologies Used

- **React + Vite, Tailwind CSS, shadcn/ui**: the student, academy, and platform interfaces
- **Node.js + Express on Cloud Functions**: the API
- **Firebase**: authentication, Firestore, storage, and hosting
