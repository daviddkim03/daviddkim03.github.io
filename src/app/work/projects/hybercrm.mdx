## Overview

Tutoring centers usually run on a patchwork of tools: one for scheduling, another for payroll, spreadsheets for session notes, and email for parents. Hyber CRM is HyberTec's own product that replaces them with one real-time platform.

## Technical Highlights

- **Live schedule**: drag-and-drop lanes per tutor with conflict detection.
- **Time clock and payroll**: kiosk PIN sign-in and pay periods with rate history.
- **Session logs and reports**: guided logs roll up into progress reports with charts and PDF export.
- **Role-based portals**: separate views for owners, tutors, parents, and students.
- **Multi-location**: each center is a branch with its own people, settings, and branding.

## Technologies Used

- **React + TypeScript, Vite**: web portals
- **Tailwind CSS + shadcn/ui**: interface
- **Firebase**: authentication, Firestore, storage, Cloud Functions, and hosting
