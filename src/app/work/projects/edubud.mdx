## Overview

EduBud International runs a learning center for adults with disabilities and volunteer chapters for students. HyberTec is rebuilding its website in its own code, keeping the existing design, so volunteer tools can be added on top. The project is in progress.

## Technical Highlights

- **Faithful rebuild**: the current site's design is kept, page for page.
- **Planned volunteer tools**: sign-in, a point tracker, one inbox for interest forms, and an events calendar.
- **Automated delivery**: every pull request gets a preview, and merges deploy automatically.

## Technologies Used

- **React Router + TypeScript, Vite**: website
- **Firebase**: hosting, with authentication and Firestore for the volunteer tools
