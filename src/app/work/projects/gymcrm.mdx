## Overview

Gym CRM gives gyms, boxing clubs, and martial arts academies one place to run coaching, classes, and payments. A public demo opens a sample gym with no sign-in.

## Technical Highlights

- **Session check-offs**: members confirm or dispute each session summary.
- **Group classes**: classes run only when enough members sign up.
- **Payments**: requests go through the head coach, who confirms and schedules sessions.
- **Workouts and meal plans**: animated exercises and plans from each coach.
- **Role-based views**: owner, coach, member, and front desk.
- **Live data**: each gym has its own database protected by security rules.

## Technologies Used

- **TypeScript + Vite**: demo, portals, and front page
- **Firebase**: authentication, Firestore, and hosting
