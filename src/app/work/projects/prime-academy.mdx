## Overview

The Prime Academy portal serves admins, tutors, parents, and students. It is built on a small multi-tenant core where each center is a branch with its own people, settings, and branding.

## Technical Highlights

- **Scheduling**: sessions and tutor availability.
- **Time and payroll**: time clock, tutor timesheets, and payroll.
- **Testing and reports**: test taking, grading, and SAT score reports.
- **Phone app**: one app for every role.
- **Tested end to end**: security rules, services, and every portal run against local emulators.

## Technologies Used

- **React + TypeScript, Vite**: web app
- **Tailwind CSS + shadcn/ui**: interface
- **Expo + React Native**: phone app
- **Firebase**: authentication, Firestore, storage, Cloud Functions, and hosting
