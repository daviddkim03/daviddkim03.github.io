## Overview

Typing Bible makes reading the whole Bible an active, shared habit for English- and Korean-speaking communities. Members type through Scripture verse by verse, keep one progress across translations, and join studies led by ministers.

## Technical Highlights

- **Typing reader**: live accuracy feedback and resume at the first untyped verse.
- **Shared progress**: typed verses count across every version and both languages.
- **Bible studies**: hosted by verified ministers who follow member progress.
- **Community**: public rankings and a board for notices, testimonies, and questions.

## Technologies Used

- **Next.js + TypeScript**: web app
- **Tailwind CSS + shadcn/ui**: interface
- **Firebase**: authentication, Firestore, analytics, and hosting
