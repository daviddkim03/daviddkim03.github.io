## Overview

hybertec.com presents HyberTec's work, services, and process, and sends new project requests straight into the company's CRM.

## Technical Highlights

- **Static export**: every page is prerendered and served from GitHub Pages.
- **WebGL hero**: the company mark rendered live as liquid chrome.
- **Content in code**: portfolio entries come from one typed list, with screenshots captured by script.
- **Lead intake**: the contact form posts to the CRM, with an email fallback.
- **Accessible motion**: the intro is skipped on repeat visits and for reduced motion.

## Technologies Used

- **Next.js + TypeScript**: static site
- **Tailwind CSS + shadcn/ui**: interface
- **Motion, Lenis, Paper Shaders**: animation, scrolling, and the WebGL hero
